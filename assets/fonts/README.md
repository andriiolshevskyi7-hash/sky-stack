# Fonts

`tiny5-*.woff2`: **Tiny5** by The Tiny5 Project Authors
(https://github.com/Gissio/font_tiny5). It is licensed under the SIL Open
Font License 1.1 (see `OFL-Tiny5.txt`) and comes from the Fontsource
distribution (latin, latin-ext and cyrillic subsets, chained as fallbacks
in `scripts/ui.gd`).

The UI draws it with no antialiasing and no hinting, always at multiples of
8 px, so every font pixel is a whole number of screen pixels.
