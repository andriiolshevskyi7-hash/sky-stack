# Графічні концепти (не в грі)

Ідеї покращення графіки, перевірені швидкими прототипами в самому рушії.
Тут лише кадри «до / після» й код прототипів. Нічого з цього не ввімкнено
в грі, поки не вирішимо, що робити.

## Стилі зображення (пост-обробка та роздільність)

| Файл | Стиль |
| --- | --- |
| `style_0.jpg` | Поточний піксель-арт |
| `style_1.jpg` | Ретро 16-біт: пікселі вдвічі більші, палітра на 32 кольори з дизерингом |
| `style_2.jpg` | HD кінематографічний: повна роздільність, сильне світіння, захід сонця, віньєтка, зерно |
| `style_3.jpg` | Нічне місто: сильне світіння й насиченість |
| `style_4.jpg` | Мультяшний / комікс: постеризація, висока насиченість |

Як зроблено: параметри `post.gdshader` (`palette_mix`, `dither_amount`,
`bloom`, `threshold`, `contrast`, `vignette`, `grain`, а також тимчасові
`saturation`, `tint`, `posterize`) і внутрішня роздільність `PixelView`
(`MAX_H` 180 / 400 / 540 / повна).

## Код прототипів

`prototypes.patch` — швидкий код зйомки (не для релізу). Застосувати:

```
git apply docs/concepts/graphics/prototypes.patch
godot --headless --import
godot res://main.tscn -- --play --nodebug --demo=clouds --aimup=0.3   # або water / storm / damage / speed
```

Що в ньому:
- глобальний uniform `demo`;
- хмари й атмосфера в `sky.gdshader`;
- імла й вода в `common.gdshaderinc`;
- дощ у `post.gdshader`;
- прапорці `--demo=` / `--aimup=` у `main.gd`;
- згасання частинок слідів біля камери у `fx.gd`.

Для справжньої реалізації потрібно:
- оптимізувати кількість кроків рей-марчингу;
- анімувати вітер;
- додати тіні хмар на землі й вхід літака в хмару;
- зробити пункт у налаштуваннях якості;
- перевірити 60 FPS на телефоні.

## HD-воксель (прототип)

| Файл | Що показано |
| --- | --- |
| `hd_zoom.jpg` | Літак крупним планом: модель 128×128×32 замість 64×64×16 |
| `hd_hangar.jpg` | Ангар у меню |
| `hd_chase.jpg` | Політ над морем |
| `hd_city.jpg` | Над містом |
| `hd_fight.jpg` | Бій |

Як зроблено (`hd_voxel.patch`):
- **Літаки** перегенеровано по-справжньому: `PlaneArt.W` 128, `D` 32,
  параметри моделей ×2, атлас 4096×2048. Деталі, намальовані в пікселях
  (панелі, заклепки, лінії), стають удвічі дрібнішими.
- **Місто, дерева, машини, кораблі**: атласи шарів, фасадів і землі подвоєно
  піксель-арт алгоритмом Scale2x (EPX). Кожен шар повторено двічі з
  половинним кроком, тож розміри об'єктів не змінюються.
- **Рендер** у повній роздільності екрана (`PixelView.MAX_H` 2000 замість
  400).

Обмеження прототипу:
- місто лише масштабоване, а не перемальоване;
- частину дрібних деталей літака (емблеми, ракети на пілонах) у HD треба
  перемалювати;
- генерація довша: атлас літаків ~1.6 с при першому запуску, далі з кешу;
- навантаження на GPU вище (пікселів удвічі-вчетверо більше).

Справжня версія:
- перемалювати генератори `SheetGen` / фасадів удвічі детальніше;
- зробити пункт «Графіка → HD-воксель» для потужних телефонів;
- перевірити 60 FPS на Pixel 9 Pro XL.
